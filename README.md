# ReachLynk Employee Management System

## Project Overview

ReachLynk Employee Management is a Java-based
web application developed using Spring Boot.

The application allows users to manage employee
records through a web-based interface.

## Technology Stack

- Java 21
- Spring Boot 3.5.7
- Maven
- Spring MVC
- Spring Data JPA
- Thymeleaf
- Bootstrap 5
- H2 Database

## Application Features

1. View all employees
2. Add new employees
3. Delete employees
4. Store employee records in a database
5. Display employee information through a web interface
